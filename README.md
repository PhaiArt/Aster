# Aster

一个本地优先的单页聊天应用：灰白极简风，角色回复由「字卡」触发，带群聊、红包、问卷、报备、通话、动态和本地数据管理。
纯前端（HTML + CSS + 原生 JS），**零依赖、无构建步骤、无后端**，可以直接部署到 GitHub Pages 并添加到手机桌面。只有导入网易云音乐时会请求外链元数据；其余数据与图片都在本机。带 Service Worker，首次在线打开后会缓存应用外壳，断网也能继续打开。

## 快速开始（本地）

1. 双击根目录的 `server.exe`（默认 8787 端口；也可运行 `server.exe 8788` 换端口）
2. 浏览器打开 <http://127.0.0.1:8787/>

也可以用任意静态服务器：

```bash
python -m http.server 8787
# 或
npx serve .
```

> 正式入口是 `index.html`（带开屏动画和 PWA 配置）；`user.html` 是同一套应用的裸页面，给测试/调试用，不带开屏。
> **不要直接双击 HTML 打开**：`file://` 下浏览器会禁用 IndexedDB，头像 / 背景 / 表情包 / 图片消息无法保存。

## 部署到 GitHub Pages

把下面这些文件放到仓库根目录（或直接把 `aster-web.zip` 解压进去）：

```
index.html
css/
js/
icons/
manifest.webmanifest
```

然后仓库 **Settings → Pages → Deploy from branch → main / (root)**，访问 `https://<用户名>.github.io/<仓库名>/`。
所有路径都是相对路径，放在项目页子路径下也能正常运行。

添加到手机桌面：

- **iOS Safari**：分享 → 添加到主屏幕
- **Android Chrome**：菜单 → 添加到主屏幕 / 安装应用

之后从桌面图标启动会以独立窗口打开，启动时播放一次开屏动画（浅色/深色跟随当前主题）。

## 外观（主题 / 气泡 / 开屏）

Me → **应用外观**：

- **主题**：浅色（默认）/ 深色 / 跟随系统。选择会立即生效并保存在本机，下次打开先按主题渲染，不闪白。
- **气泡形状**：经典 / 胶囊 / 方正 / 尖角。
- **气泡颜色**：雾灰 / 墨黑 / 暖杏 / 雾蓝 / 淡紫 / 樱粉 / 薄荷。深色主题下每种颜色有单独调过的深色版本；我的气泡和对方气泡可以分别选色。
- **气泡尺寸**：左右内边距 / 上下内边距 / 气泡间距三根滑杆，可在应用外观页的气泡预览里直接看效果。
- **壁纸**：四个主页面可统一用一张，也可 Chats / Discover / Life / Me 分别设置；支持预设和本地图片，聊天详情跟随 Chats；可调壁纸透明度、缩放和水平/垂直位置。
- **毛玻璃**：卡片、顶栏、底栏、气泡半透明并带背景模糊，轻 / 中 / 强三档；音乐小组件、顶部弹窗、音乐悬浮窗和经期/音乐专属卡也已玻璃化。
- **气泡**：我的气泡和对方气泡可以分别选颜色；支持自定义气泡 CSS，完整选择器或直接写声明都可以。
- **引用回复**：角色回复时可按概率引用你最近 10 条消息中的一条，概率在「回复设置」里调。
- **动态字卡**：字卡设置新增「动态」子类；角色每天有 0–2 条动态机会，每条从动态字卡抽 1–6 张拼成文案。发送概率、最少/最多字卡数在「回复设置 → 角色动态」里调。
- **待办 / 经期提醒**：Me → 提醒设置。默认在 48 / 36 / 24 / 8 小时前提醒，可改四个时间点；待办和经期分别可多选提醒角色，每个角色有独立话术。错过节点只在打开网站时合并成一条当前剩余时间的提醒，过了截止不再补发。
- **桌面通知**：提醒设置里可申请通知权限并发送测试通知；Android Chrome / iOS Safari 需先安装到桌面。网页在后台但仍存活时，新消息/提醒会通过 Service Worker 发到手机通知中心。完全关闭 App 或被系统挂起后的定时推送需要服务端 Web Push，纯静态站点无法独立保活或定时唤醒。
- **时间戳**：聊天里居中显示；间隔可选 5 / 15 / 30 / 60 分钟或仅跨天，跨天时时间跟随日期行。
- **字号 / 减少动画 / 触感反馈**。
- **开屏**：每次打开播放一次（内部路由切换不播放），点一下可跳过；深浅色跟随主题；开启「减少动画」后只快速淡出。

## 数据保存在哪

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 联系人、聊天、动态、设置（含主题/气泡） | `localStorage` 的 `sq_state_v1` | 文本数据，约几十 KB |
| 头像、背景、表情包、图片消息 | `IndexedDB` 的 `sq-chat-db` | 图片压缩后存储 |

「Me → 本地数据管理」提供：

- **导出全部数据 (JSON)**：文本数据备份，**不含图片**
- **导入备份 (JSON)**：整体覆盖当前数据（图片不会被覆盖）
- **清空并重置**：同时清空 localStorage 与 IndexedDB 中的图片

## 功能速览

- **Chats**：单聊 / 群聊切换、分组（可改名/删除）、搜索、置顶、新增联系人/群聊
- **聊天**：文字、图片、语音、表情包、报备、问一问问卷、红包（拼手气按人均随机浮动分配）、转账、通话、戳一戳（群聊先选人再拍）、引用回复；角色要回复时，底部工具栏上方显示「备注名/角色名 正在输入...」
- **角色资料**：聊天右上角「…」第一项进入，单独浏览该角色的全部动态；可以「以该角色身份」发文字/图片动态，也可以从字卡里选一条代发
- **群聊回复**：每个成员各自独立判定是否回复、回几条、间隔多久（各自抽各自的字卡池），相当于同时扭多台扭蛋机；群里「不回」就是安静
- **聊天设置**：聊天背景（预设/导入）、角色背景图、头像与气泡布局（带头像实时预览）、聊天分组（把联系人移到任意分组）、时间戳、已读状态、自动滚动、触感反馈、角色资料（昵称/备注/Handle/签名）、记忆备忘录、聊天数据导出/清空
- **报备字卡**：一组 = 多句文字 + 多张 1:1 图片；发送时随机一句，50% 概率再带一张随机图片，句子/图片概率均等；可随时改字、删图、加图，支持一次批量导入多张图片。回复设置里可调「发送报备概率」
- **表情包 / Emoji**：Me → 表情包管理是独立页面，可导入图片表情、添加/删除 Emoji，图片表情支持批量导入；两者都会进入角色回复池。回复设置里「图片表情概率 / Emoji 概率」默认 12% / 18%，Emoji 一半单独发一条、一半跟在字卡后面
- **Life**：第四个底部 tab，六张卡点击后以「组件放大」动画进入独立页。番茄钟支持 25/45/60 普通计时，也可选角色陪伴；陪伴时每 2 分钟从通用 + 专属字卡抽一句话，显示角色头像并保留陪伴消息历史。听音乐是封面 + 进度 + 控制 + 队列的播放页，支持本地音频文件和网易云链接导入（本地文件导入时可手动填歌名/歌手，网易云自动获取歌名/歌手，保存在本机）；离开音乐页后仍继续播放，并在页面底部出现悬浮窗（歌名、进度条、上一首/播放/下一首/关闭播放），可收成只滚动歌名的小胶囊；展开态和收起态都可以拖动，位置会保存；一起听有独立页面，双头像、同步计时、共享歌单和一起听记录，只记录一起听了几分钟。倒数日单条用大数字、多条紧凑排布，未来 / 过去 / 多事件分别有淡蓝、暖橙、双色底；待办截止日期必填，桌面组件按 DDL 排序并可直接勾选；经期有周期环、可翻前后两个月的日历、排卵期标记和量/痛/症状轻记录，日历上可直接点日期标记/取消实际经期，小组件用四段阶段条；记账支持收入/支出记录。照片 4×2 仍支持导入本地照片
- **Discover**：social media 只显示我的动态，点「N posts」进入「我的动态」看自己的全部动态（该页不再重复 social media 概览）；moments 显示所有角色 + 我的动态；我可以评论任何角色的动态；角色动态可一键分享到与它的聊天；我的动态可分享到任意单聊/群聊，聊天里显示动态卡片，点开看全文；发布动态支持批量选择图片（最多 3 张）
- **主动互动**：回复设置里可调「主动发消息 / 拍一拍 / 发红包 / 打视频」的权重。拍一拍会补一句回复；红包被领取后角色会回话；角色发起视频邀请时会弹出 3:4 的等待接听小窗，接听后进入通话；通话收起的悬浮球可拖动。默认 60/20/12/8，按每天约 1.5 小时、3–5 次打开调整
- **顶部角色消息横幅**：角色发来新消息且你不在该聊天时，从顶部滑下一条玻璃横幅，4 秒自动收起；点按进聊天，可上滑手动收起，无关闭按钮。
- **Me**：编辑资料与封面、收藏、表情包管理、字卡设置、我的报备、回复设置、提醒设置、应用外观、本地数据管理

### 角色为什么会「已读不回」

角色回复来自「字卡」（Me → 字卡设置，通用 + 每个角色专属）。
**没有字卡时角色只会回「已读不回」**，这是预期行为，不是坏了；加几条字卡即可。
回复延迟、条数、已读不回概率、主动消息开关都在 Me → 回复设置。

## 已知限制

- 单文件 JSON 备份不含图片，无法跨设备恢复图片
- 数据只存在当前浏览器，清理浏览器数据会丢失；换设备/换浏览器不会同步
- 聊天页收到新消息只重建消息区（不会清掉输入框草稿），但列表页等仍是整页重渲染
